Alur Proses - Aplikasi Android KampusPay (Mahasiswa)

Flowchart dipisah per alur supaya jelas saat dicetak dan mudah dijelaskan.

Flowchart Android 1 - Login & Dashboard
flowchart TD Start([Mulai]) Start --> A[Halaman Login Android] A --> B[/Input Username & Password/] B --> C{Validasi API} C -->|Tidak| A C -->|Ya| D[Dashboard Mahasiswa] D --> M1[Pembayaran / Tagihan] D --> M2[Riwayat] D --> M3[Laporan] D --> M4[Kwitansi] D --> M5[Aktivasi] D --> M6[Profil & Ubah Password] D --> M7[Logout] M7 --> End([Selesai])
Flowchart Android 2 - Alur Pembayaran Mahasiswa
flowchart TD D[Dashboard Mahasiswa] D --> M1[Pembayaran / Tagihan] M1 --> Tag[Lihat Daftar Tagihan] Tag --> PilihTagihan[Pilih Tagihan] PilihTagihan --> Metode[Pilih Metode Pembayaran] Metode --> T1[Tunai] Metode --> T2[Transfer] Metode --> T3[Cicilan] T1 --> S1[Status: Menunggu Bayar di Kasir] S1 --> K1[Simpan Kode Pembayaran] K1 --> K2[Datang ke Kasir dengan Kode] T2 --> U1[Upload Bukti Transfer] T3 --> U2[Input Jumlah Cicilan] U2 --> U1 U1 --> V1[Kirim via API] V1 --> V2[Menunggu Verifikasi Kasir di Web] V2 --> R{Kasir Verifikasi} R -->|Setujui| OK[Pembayaran Tercatat] R -->|Tolak| Reject[Status Ditolak - Upload ulang] OK --> End([Selesai])
Flowchart Android 3 - Notifikasi Tagihan ke Mahasiswa
flowchart TD A[Admin atau kasir membuat tagihan di web] A --> B[Simpan tagihan ke database] B --> C[Generate kode pembayaran] B --> D[Notifikasi in-app ke mahasiswa] C --> E[Kirim email ke mahasiswa] E --> F[Mahasiswa membaca email] D --> G[Mahasiswa melihat notifikasi di aplikasi] G --> H[Mahasiswa membuka detail tagihan]
Flowchart Android 4 - Alur Aktivasi Mahasiswa
flowchart TD D2[Dashboard Mahasiswa] D2 --> M5[Aktivasi] M5 --> A1[Buka Menu Aktivasi] A1 --> A2[Pilih Status: Aktif atau BSS] A2 --> A3[Submit via API] A3 --> DB[(Database)] DB --> A4[Data Aktivasi Tersimpan] DB -.-> N[Notifikasi ke Kasir Web] N --> K1[Kasir lihat di Menu Aktivasi] A4 --> End([Proses Aktivasi Selesai])
